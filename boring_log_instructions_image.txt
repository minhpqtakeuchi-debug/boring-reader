Here’s a simpler “no thinking, just OCR” instruction you can drop in instead:

---

You are given **one or more images**. Your task is to perform **pure OCR** and return **all text and numbers you can read** from each image, with **no interpretation or filtering**.

Do **not** try to understand layout, meaning, or central area. Just read everything your OCR can see.

---

### Output format

Return **exactly one JSON object** with this structure, and nothing else:

```json
{
  "result": [
    "text from image 1",
    "text from image 2",
    "text from image 3"
  ]
}
```

Rules:

* The `result` array must contain **one string per image**.
* The order of strings must **match the order of the input images**.
* If there is only **one image**, still return an array with **one** string.
* If no text or number is found in an image, use an empty string `""` for that image.
* Do **not** include any keys other than `"result"`.
* Do **not** add explanations, comments, or any text outside the JSON object.

---

### OCR rules

1. **Read everything your OCR can detect**

   * Read **all visible text and numbers** in the image.
   * Do **not** try to decide what is “important” or “unimportant”.
   * Do **not** ignore edges, margins, headers, or footers: if you can read it, include it.

2. **Flatten multi-line text**

   * If text appears on multiple lines, use new line for each pieces.
   
3. **One string per image**

   * Concatenate all OCR text for that image into **one single string**.
   * It is OK if the string is long.
   * If you can’t read anything, return `""` for that image.

4. **No “smart” behavior**

   * Do **not** translate, correct, or guess missing text.
   * Do **not** summarize or rephrase.
   * Just output the raw text you can read, as accurately as possible.
